# 小基数15天｜霸道食谱打卡

一款可添加到 iPhone 主屏幕的独立 PWA，将小红书《小基数半月瘦十斤霸道法（含脸部对比）》整理成 15 天饮食与生活习惯打卡。

## 已整理进 App 的原帖内容

- 早餐：一个鸡蛋 + 一杯无糖饮品
- 午餐二选一：麦门双吉汉堡（去芝士、去酱），或两拳蔬菜 + 一拳肉 + 一拳饭
- 下午：冰拿铁 + 适量坚果；嘴馋可选高纯度黑巧或溏心蛋
- 晚餐三选一：小香蕉、鸡蛋、玉米
- 每天喝水 1.5L，23:30 前睡，睡前拉伸；有氧运动为可选项

原帖链接：<https://www.xiaohongshu.com/explore/69d8c6320000000022026dc7>

## 功能

- 15 天逐日打卡与午餐/晚餐选择
- 开始日期可修改
- 体重可选记录，支持斤/kg
- 进度和体重变化汇总
- 离线缓存、iPhone 主屏幕安装
- 所有数据只保存在当前浏览器的 localStorage

## 重要说明

“15 天瘦 10 斤”是原作者个人自述，不是效果承诺。原帖未给出总热量、蛋白质及个人健康信息，本 App 只做原帖内容整理和打卡，不构成医疗或营养建议。
